How to read these numbers

One record is one stored projection row, not one model request or shell subprocess. Run, plan and provider-usage metadata are included in the archive total. Main-agent scoped final usage is summed separately across root and children; the rolling context-window meter is excluded. Cached input is part of input, and reasoning counts are already part of output.

Archive hashes and row counts are validated before this report is generated. Referenced child discovery does not recover unrelated threads, deleted records, native assets, missing attachments, or intermediate streaming revisions. Private reasoning/internal prompt bodies and secret-request payloads are omitted; binary and credential-like content is scrubbed. This report makes no new claim about game fidelity or completion.
