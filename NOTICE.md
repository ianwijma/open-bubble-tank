# Attribution

Bubble Tanks 3 was created by Hero Interactive. Its original artwork, music, sounds, text, and authored tank designs are credited to their original creators.

This repository reconstructs game behavior from the research in `documented-bubble-tank-3`. The browser SWF parser originated in that repository's `research/swf-browser-extraction` demo and has been extended and corrected here.

No original SWF, exported game images, or extracted audio files are bundled. Players select their own game file locally; mock artwork is generated procedurally when no file is supplied. Numerical part/wave definitions and recovered tank layouts are included as research-derived data.

Third-party runtime dependencies retain their respective licenses in their packages: Next.js, React, Tailwind CSS, and PixiJS. Original game assets remain distinct from the recreation's source code.
